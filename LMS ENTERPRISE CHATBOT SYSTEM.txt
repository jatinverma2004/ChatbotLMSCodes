LMS ENTERPRISE CHATBOT SYSTEM
Run Instructions (Windows CMD)

Docker (Easiest):
1. docker run -d -p 27017:27017 --name mongodb mongo
2. That's it! MongoDB running on port 27017
 

Run these commands in your chatbot_service and mcp_v3_server directories:
 
pip install pymongo --break-system-packages
pip install python-multipart --break-system-packages
pip install pillow --break-system-packages
pip install openpyxl --break-system-packages
pip install python-docx --break-system-packages
pip install pdfplumber --break-system-packages
 
[React Updated commands]

2. enter below commands along with the old commands of backend servers
pip install groq
npm install -g serve

cd jio-assistant-react
npm run build
npx serve -s build
npx serve -s build

1. CREATE / ACTIVATE PYTHON VIRTUAL ENVIRONMENT

cd mcp_v3_server

python -m venv venv

venv\Scripts\activate

uvicorn main:app --reload --port 8100

2. INSTALL REQUIRED DEPENDENCIES

pip install fastapi uvicorn streamlit requests pypdf python-docx sentence-transformers langgraph


3. START MCP V2 SERVER

cd mcp_v2_server

venv\Scripts\activate

uvicorn app.main:app --reload --port 8000


4. START MCP V3 SERVER

cd mcp_v3_server

venv\Scripts\activate

uvicorn main:app --reload --port 8100


5. START CHATBOT SERVICE


cd chatbot_service

venv\Scripts\activate

uvicorn app:app --reload --port 9000


6. START LANGGRAPH SERVICE (IF USED)

cd chatbot_service

venv\Scripts\activate

uvicorn langgraph_system.langgraph_chat:app --reload --port 9100

7. START CHAT UI

cd chatbot_service

venv\Scripts\activate

streamlit run chat_ui.py
